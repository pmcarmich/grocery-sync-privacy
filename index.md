# Grocery Expense Sync Privacy Policy

**Last updated:** October 17, 2026

## Overview

Grocery Expense Sync is a personal automation application that imports grocery purchase information from Gmail into Splitwise.

## Information Accessed

The application requests read-only access to Gmail to retrieve Walmart and Instacart grocery receipts.

It extracts relevant information, including:

- Retailer and order number
- Purchase or delivery date
- Final charged amount

## How Information Is Used

Extracted grocery expenses are submitted to Splitwise using its API to track shared household expenses.

Gmail information is not used for advertising, sold, or shared with unrelated third parties.

## Data Storage and Security

The application uses OAuth authentication to access Gmail. Authentication credentials are stored as private GitHub Actions secrets.

The application may retain order identifiers and Splitwise expense identifiers to prevent duplicate imports.

## Data Retention and Deletion

The application owner can revoke Gmail access through Google Account settings and delete stored application credentials and processing records.
